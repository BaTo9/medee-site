# TUGEE.mn (ТҮГЭЭ) — мэдээний сайт

Мэдээг түгээ: Zarig.mn-тэй төстэй зохион байгуулалттай мэдээний сайт.
Лого: улбар шар тэмдэг доторх цагаан «түгээх» (share) дүрс + TUGEE.mn бичиг.

- Улбар шар наалддаг толгой + үндсэн цэс
- TREND мөр (огноо, ханш, цаг агаар)
- Зүүн талд «Шинэ мэдээ» цаг дарааллын жагсаалт, дунд нь онцлох мэдээний сүлжээ
- Улс төр / Нийгэм хоёр багана, хар дэвсгэртэй Видео мэдээ бүс
- Нийтлэлчид, Орон нутаг хэсгүүд, хар хөл
- Мэдээ дээр дарахад дэлгэрэнгүй цонх, хайлт, ангиллаар шүүх, гар утасны цэс

Одоогийн мэдээнүүд нь бүгд жишээ (туршилтын) агуулга — жинхэнэ мэдээ, зураг, холбоо барих мэдээллээр дараа нь солино.
